# Casa Trigoso

## Versione privata Supabase

La versione pubblica continua a essere disponibile su GitHub Pages:
https://christian-salvaneschi.github.io/casa-trigoso/

La versione privata è servita da una Supabase Edge Function con accesso tramite codice generale:
https://dnlrikrqzyspxxsrvovu.supabase.co/functions/v1/casa-private

Il progetto Supabase è `Casa Trigoso` (`dnlrikrqzyspxxsrvovu`) nella stessa organizzazione usata da GroupPick. I segreti `CASA_ACCESS_PASSWORD`, `CASA_SESSION_SECRET` e `CASA_STORAGE_SERVICE_KEY` sono configurati solo nel progetto Supabase e non devono essere aggiunti al repository.

Sito statico bilingue (francese predefinito, italiano selezionabile) per le informazioni private dell’appartamento.

Aprire `index.html` in un browser oppure pubblicare i tre file `index.html`, `styles.css` e `app.js` nella stessa cartella di un hosting statico.

## Privacy

La dicitura “Espace privé / Area privata” è solo grafica. Per inserire password Wi‑Fi, codici delle chiavi o contatti personali è necessario proteggere l’hosting con autenticazione.
